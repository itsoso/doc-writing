# Worked example: from generic mobilization to a traceable viewpoint

This example is synthetic. It contains no real meeting, person, project, or internal figure.

## Source notes

- A pilot shopping assistant recommended products but did not check delivery time.
- Several testers reached checkout before noticing the item would arrive too late.
- The product owner said: “The problem is not that the answer sounds bad. We have not finished the user's task.”
- Next experiment: add delivery estimates for internal testers only and review failures daily.
- Concern: inventory and logistics timestamps can be delayed, so the assistant must state uncertainty.

## Evidence ledger

| Candidate claim | Status | Support |
|---|---|---|
| The current weakness is task completion, not conversational fluency | Sourced | Direct product-owner statement |
| Delivery information should enter the next experiment | Sourced | Explicit next step |
| A fluent answer can hide an incomplete transaction path | Inference | Connects the failed test and stated diagnosis |
| The assistant should never recommend products | Unsupported | Contradicts the intended next experiment |

## Voice map

- Notices the gap between polished interaction and completed user work.
- Prioritizes a small production experiment over a broad product declaration.
- Protects user trust when source data is uncertain.
- Uses a diagnostic contrast: “not how it sounds, but whether the task is finished.”
- Is confident about the next experiment and conditional about expansion.

## Weak paragraph

> 在智能化快速发展的时代，我们要全面拥抱购物助手带来的历史机遇，以用户价值为核心抓手，强化技术、产品和运营协同，打通全链路闭环，持续赋能业务高质量发展。首先要统一认知，其次要加快落地，最后形成可复制的方法论。

Why it fails:

- Nothing can be traced to the source notes.
- The product owner's diagnostic contrast has disappeared.
- Abstract terms occupy the paragraph, but the failed user task is absent.
- The requested action has no experiment boundary, owner, or feedback.
- The paragraph could describe almost any AI product.

## Revised paragraph

> 这次试用暴露的问题，不是助手回答得不够流畅，而是它没有完成用户真正交给它的任务。几名同事要求寻找能按时送达的商品，助手给出了推荐，却直到结算页才让人发现配送时间不合适。下一轮我们先不扩大范围，只为内部试用接入预计送达时间，由产品和工程每天复盘失败记录。一周后再决定是否继续扩展。库存和物流信息存在延迟时，助手必须说明更新时间和不确定性，不能把推测说成承诺。

Why it is stronger:

- It opens with the author's actual judgment.
- The example earns the conclusion instead of decorating it.
- The action has scope, feedback, and a later decision.
- The risk is connected to a concrete system behavior.
- Sentence and paragraph rhythm follows the argument rather than a template.

## Lesson

Removing “AI flavor” is not a synonym-replacement exercise. The decisive edit restores source, judgment, consequence, and action. If those are missing, stylistic variation only makes generic writing harder to notice.
