## 何时加载本参考

仅在以下任一条件成立时使用：

- 用户明确提供快手 OnePoint 会议链接；
- 用户要求从 OnePoint 查找、查看或总结会议；
- 用户明确说明当前任务位于快手内部环境。

不要因为材料里出现“会议”“纪要”或其他同名产品就调用 OnePoint。无法确认是否属于快手内部时，先把 OnePoint 视为不可用，使用用户提供的文本或询问来源。

## 先遵循内部安装与授权规范

OnePoint CLI 会持续更新。每次使用前，按照[公司内部 OnePoint CLI 授权文档](https://bs3-hb1.corp.kuaishou.com/kwaishop-langbridge-evaluation/onepointcli.md)校验本机版本与登录状态；不要把该内网文档的安装脚本复制进公共 Skill，以免发生版本漂移。

验证命令是否存在：

```bash
onepoint --help
```

已有有效登录态时应复用本地凭证。需要 Agent 协助首次授权或凭证失效时，使用：

```bash
onepoint login --no-open-browser
```

原样把 CLI 给出的授权 URL 交给用户，并优先在用户已有登录态的浏览器中打开。不要记录、改写或公开授权 URL、设备密钥、API Key、凭证文件内容。网页显示授权完成后，仍要等待 CLI 自身校验成功，再运行：

```bash
onepoint whoami
```

除非用户明确要求重新授权，否则不要使用强制登录参数。登录或权限失败时只报告当前错误，不尝试绕过权限或自动重复授权。

## 定位会议

如果用户给出 OnePoint 页面链接，从 URL 路径中提取 `<meetingId>`；不要把真实会议链接或 ID 写进插件、测试、README、提交信息或公共日志。

如果用户只描述了会议，先列出小范围候选：

```bash
onepoint meeting list --keyword "<关键词>" --last-n-days 30 --limit 10 --output compact_json
```

也可以根据用户范围使用 `--today`、`--this-week`、`--last-week`、`--since` 或 `--until`。不要无边界拉取全部历史会议。候选不唯一时，列出标题与时间让用户确认，不要凭主题猜测。

## 读取会议材料

需要完整分析时：

```bash
onepoint meeting view <meetingId> --full --output compact_json
```

只需要部分字段时：

```bash
onepoint meeting view <meetingId> --include summary,actions,asrText,documents --output compact_json
```

按不同字段的用途处理材料：

- `summary`：快速了解会议主题和结构，不直接当作说话者原话；
- `actions`：识别明确承诺、责任人和后续事项；
- `asrText`：核对观点、措辞、限定条件与争议，是发言归因的主要证据；
- `documents`：补充会议关联材料，只读取当前任务真正需要的内容。

会议仍在 processing、内容为空或字段缺失时，明确报告当前状态。不要用常识补全缺失发言，也不要把自动摘要中的推断写成确定事实。

## 从会议内容提取“我的观点”

1. 先确认“我”对应哪个参会者。优先使用明确的参会者、说话者或账号信息；不能可靠对应时向用户确认。
2. 以 `asrText` 中可归因的原始发言建立证据账本，再用 `summary` 辅助理解上下文。
3. 将会议中的问题、他人观点、用户本人的判断和最终共识分开，不能把团队共识全部归给用户。
4. 保留反复强调的词、因果判断、取舍、疑问和保留意见。口语噪声可以整理，观点边界不能改变。
5. `actions` 只证明会议记录中的行动项；若责任人或截止时间不明确，应保留不确定性。
6. 多场会议合并时记录每个判断的来源会议，但在最终文章中只按用户需要展示来源细节。

完成取材后，回到主 Skill 的证据账本、声音地图、叙事骨架和发布门禁，不要把 OnePoint 字段顺序直接变成文章目录。

## 内部数据边界

- 只读取用户明确授权且当前账号有权访问的会议。
- 不把完整 ASR、内部链接、真实 meetingId、参会人名单或敏感业务信息提交到公共仓库。
- 输出给外部受众前，重新确认发布范围并做必要脱敏；内部可访问不等于可以对外发布。
- 调试参数只在定位问题时使用，分享日志前删除认证信息、请求上下文和内部标识。
- CLI 或内网不可用时，请用户提供已授权的文本或导出材料；通用写作流程仍然可用。

## 最小故障处理

| 现象 | 处理 |
|---|---|
| 找不到 `onepoint` | 按内部授权文档校验并安装最新版，不复制旧安装命令 |
| 登录失效 | 运行登录流程并等待 CLI 完成身份校验；不要只看网页状态 |
| 无会议权限 | 停止读取并请用户确认权限或提供授权材料 |
| 候选会议不唯一 | 展示小范围候选，请用户确认 |
| 会议仍在处理 | 报告状态，等待用户决定是否稍后重试 |
| ASR 归因不清 | 标为无法确认，不猜测说话者 |

任何故障都不应降低来源标准。拿不到材料时，应说明限制，而不是生成一个看似完整的会议分析。
